## ③ 批注弹窗里的点击误激活高亮（**最费劲的一个**）

### 我错了两次

-> 第一次以为是 `::selection` ❌
-> 第二次以为是 `multiply` 叠乘 ❌
-> 用户三次说"我说的是**高亮**高亮" -> 我才去看**谁调用了 `setActiveHighlightId`**

### 真因

-> 批注弹窗在 **React 树里是 `.scpdf-container` 的后代**
（代码注释自己写了"React 的合成事件照样冒泡"）
-> 容器上有**高亮的点击委托**（按**鼠标坐标**命中）
-> 在弹窗里点"加粗" -> 坐标正好落在**下面的高亮**上 ❌
-> `handleHighlightClick` -> `setActiveHighlightId` -> **蓝色选中边框** ❌
-> 1.5s 自动消失的定时器**只在非批注分支**里 -> **一直蓝着** ❌

### 复现（把弹窗挪到高亮上，点弹窗里的按钮）

```
点击后: hasActive=true  outline: solid 2px rgb(47, 84, 235)
+500ms -> true  +1500ms -> true  +3000ms -> true  +5000ms -> true
```

### 修法（四层）

1. 容器加 `onClickCapture` -> **捕获阶段**就拦掉来自浮层内部的点击
2. 浮层根节点打 `data-scpdf-floating` 标记
3. 正在批注时**根本不设置**激活态
4. 安全网：`activeHighlightId` 非空时**保证 1.5s 后清掉**

> ⚠️ **踩坑**：捕获阶段 `stopPropagation()` -> 事件**到不了自己的 target**
> -> 弹窗里"新建批注 / 关闭 / 取消 / 保存"**全部点不动** ❌
> -> 用户反馈："新建批注这个按钮现在无法点击了"
> -> 改成：**捕获阶段只打标记**，**冒泡阶段自己跳过**

## ⑤ 便签难 hover

### 实测

```
便签图标 22×22 px
命中: (+11,+11)✅  (-2,-2)❌  (+11,-3)❌     <- 差 2~3px 就落空
内容框 left:26px -> 图标右边 4px 空隙 -> 鼠标穿过 -> mouseleave -> 框消失 ❌
```

### 修法（三层）

1. **热区 36×36**（`::before` 透明）-> 视觉不变，命中范围变大
2. **桥接区**（透明元素盖住那 4px 空隙）
3. **延迟 200ms 关闭**（最关键）
   -> 中间那一瞬间的空隙**不会**导致消失
   -> 鼠标真走了还是**会关**（不粘着）
