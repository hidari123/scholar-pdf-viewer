## 一、功能缺口

### 缺口 1：`slots` prop（方案 D）完全没做 ❌

计划的"具体要新增的 #4"明确写了：
> 新增 `slots` prop（方案 D 也一并做了，成本不高）

之前只有 `Toolbar` 自己的 `leftSlot` / `rightSlot`（**已有的 toolbar 配置**），
不是计划要的 `slots={{ toolbar, panel, pageOverlay }}` → **0/3 实现**。

**实现**：

- `core/theme/index.ts` → 新增 `PdfViewerSlots`（`toolbar` / `panel` / `pageOverlay`）
  - ⚠️ 类型用 `unknown` 而不是 `ReactNode` → **core 层保持零 React 依赖**（core 的铁律）
- `PdfViewer.tsx` → 新增 `slots` prop
  - `toolbar` 给了 → **整个替换**内置 `<Toolbar>`
  - `panel` 给了 → **整个替换**内置 `<ThumbnailPanel>` / `<OutlinePanel>`
  - `pageOverlay` 可以是**函数** → 按页号调用（能拿到"当前是第几页"）

**测试**：E2E `scripts/e2e-slots.mjs`（7 项，**全绿**）

```

```

### 缺口 2：`appearance` 的 `accentColor` / `fontFamily` / `fontSize` 缺失 + `showPageNumber` 是死 prop

计划 §方案C 明确列了前三个（可选字段）→ 补上。

⚠️ **`showPageNumber` 之前是"死 prop"**：
grep 全仓库确认它**只在类型里声明**，从没被读过 → **传了完全没效果**。

→ 现在真正生效：
- `themeClasses` 产出 `scpdf-root--no-page-number` / `scpdf-root--show-page-number`
- CSS 控制工具栏的翻页器（`.scpdf-toolbar__pager`）

⚠️ **`pageRadius` 之前只支持 `=== 0`**（class 表达不了任意数值）
→ 新增 `appearanceStyles()` → **任意值走内联 CSS 变量**：

```ts
pageRadius: 8   → --scpdf-radius-page: 8px
accentColor: '#f00' → --scpdf-color-primary: #f00
fontFamily: '...'  → --scpdf-font-family: ...
fontSize: 14    → --scpdf-font-size: 14px
```

### 缺口 3：`setActiveSearchIndex(-1)` 没实现（用了 `0`）

计划明确要求 `-1`（"没有激活命中"）。

→ 已改成 `-1`：
- `activeSearchIndex` 是 **0-based** 的数组下标
- `0` 意味着"第 0 个命中是激活的" → **语义不对**（明明一个命中都没有）
- `-1` → `searchHits[-1]` 是 `undefined` → `activeSearchIndexOnPage` 返回 `null`
  → **渲染上无差异**，但语义正确

## 二、真 bug（审计 + 实测发现）

### bug 1：打印时页还是绝对定位 → **重叠 / 丢页**（最严重）

**实测（修复前）**：

```
position: absolute; top: 16px / 1854px / 3691px …   ← 18 页各自定位
```

→ 打印时：
1. 18 个**绝对定位**的页 → 浏览器按绝对位置分页 → **重叠 / 大量空白页**
2. 绝对定位的页**不撑开父元素** → 打印流里只剩第一页的位置 → **后面的页全丢**

**修复**（`viewer.css`）：

```css
.scpdf-page {
  position: static;      /* ← 关键：改回正常流 */
  top: auto;             /* ← 干掉内联的绝对定位偏移 */
  margin: 0 0 12px;      /* 页间距 */
}
```

**实测（修复后）**：

```
position: static
rectTop: 8 / 1842 / 3675 / 5509 / 7342   ← 依次排列，没有重叠 ✅
```

**回归测试**：E2E `e2e-print.mjs` **+2 项**（12 → **14 项**，全绿）

- **打印时页是静态流**（不是绝对定位 → 不会重叠 / 丢页）
- **打印时各页依次排列**（top 递增 → 没有重叠）

### bug 2：`transform: scale()` 不改变布局盒 → 每页后面多一截空白 → **空白页**

旧的写法：

```css
margin-bottom: calc((var(--scpdf-print-scale, 1) - 1) * 100%);   /* ❌ */
```

`margin` 的百分比是**相对宽度**的，不是高度 → 这个式子根本收不回空白。

**修复**：**同时把 `height` 缩掉**（`height` 是内联样式 → 要 `!important`）：

```css
.scpdf-page {
  height: calc(var(--scpdf-page-height, 100%) * var(--scpdf-print-scale, 1));
}
```

`--scpdf-page-height` 由 `usePrint` 在打印前**逐页**写好
（PDF 每页可以不同尺寸 → 必须逐页写）。

### bug 3：`usePrint` 从没被包内用；内联版打印后**不恢复缩放**

之前 `PdfViewer` 的 `onPrint` **自己手写**了一遍"算缩放 → setProperty → 双 rAF → print"
→ **`--scpdf-print-scale` 永久残留** → 而且和 `usePrint` 逻辑重复。

**修复**：

- `PdfViewer` 改用 `usePrint({ pageSizePt: pageSizesPt[0], paper: 'A4' })`
- `usePrint` 顺手修 3 个问题：
  1. **`margin` 对象在依赖数组里** → 宿主每次传字面量 → `print` 每次都是新函数
     → 拆成 4 个 number 依赖
  2. **`onAfterPrint` 会调两次**（`afterprint` 事件 + `setTimeout` 兜底谁先谁后）
     → 加 `restored` 标志 → **只恢复一次**
  3. `onAfterPrint` 放进 **ref**（避免 inline 箭头函数进依赖）

### bug 4：高亮操作条的锚点**滚动后过期**

`measureHighlightRect` 只在点击时算一次 → 滚动 / 缩放后浮层脱离高亮块。
而且 `SelectionPopover` 的实时校正轮询在"外部锚点"模式下是**跳过的** → 不会自愈。

**修复**：新增 effect → **滚动 / 缩放 / 换页时重算锚点**
（rAF 节流 + 只在真的变了才 setState）。

## 三、其他

- **打印隐藏规则加 `!important`** → 宿主自己的 CSS 特异度可能更高
  → 打印时工具栏会被打出来
- **暗色主题补 `--scpdf-radius-page`** → 之前暗色下沿用 `:root` 的 2px
  → 和 `contrast` / `minimal`（0px）不一致 → **每套主题都要完整**
- **`HighlightDoc.highlights` 类型 `unknown[]` → `HighlightRecord[]`**
  → 宿主不用再写 `doc.highlights as HighlightRecord[]`（demo 里那行断言删了）
  → 运行时**仍然逐条校验**（不合法���条目丢掉，不让包崩）
- **修掉一条与实现不符的注释**（`handleHighlightClick` 里写着 `removeAllRanges()`，
  实际用的是 `clearNativeSelection()` → `collapseToStart()`）
