# 测试样张清单（PDF fixtures）

> 实际 PDF 不提交 git（体积大）；本文件固定"该测什么、从哪来、每个文件验证什么"。
> 文件放 `test-fixtures/`（已 gitignore），由开发者自行放置。

| #   | 样张                              | 验证点                        | 错误码 / 边界                          | 获取方式                       |
| --- | --------------------------------- | ----------------------------- | -------------------------------------- | ------------------------------ |
| S1  | 常规多页文本 PDF（≥10 页）        | 基础渲染 / 分页 / 选区 / 高亮 | —                                      | Word/LibreOffice 导出          |
| S2  | 含图片 PDF（照片页）              | 图片渲染、缩放清晰度          | E_RENDER_PAGE                          | 制作                           |
| S3  | 大 PDF（≥50 页 / ≥10MB）          | 首屏时间 / 翻页延迟 / 内存    | 性能规格（方案 §10）                   | 公版书（如 Project Gutenberg） |
| S4  | 加密 PDF（打开密码）              | 密码流程                      | E_PDF_ENCRYPTED / E_PDF_PASSWORD_WRONG | Acrobat 设密码                 |
| S5  | 扫描件（纯图片无文本层）          | 无文本选区、rects 高亮仍可用  | —                                      | 扫描件 / 图片型 PDF            |
| S6  | 中文 / CJK PDF                    | 字体回退、选区正确性          | —                                      | 中文内容导出                   |
| S7  | 含链接 PDF（内部跳转 + 外部链接） | 链接处理                      | E_LINK_INVALID                         | 制作                           |
| S8  | 旋转页（90/180/270）              | 旋转下的坐标换算              | viewport API vs 纯数学回退             | 制作                           |
| S9  | 损坏 / 非 PDF 文件                | 错误路径                      | E_PDF_INVALID                          | 截断文件 / txt 改名            |
| S10 | 空 PDF（0 页）                    | 边界                          | E_EMPTY                                | pdf-lib 生成                   |

**验收分级**：S1–S3、S6 为 P0（必须全过）；其余 P1。
与方案 §9 边界矩阵一一对应；阶段 2+ 每次回归在此表打钩并记录表现。
