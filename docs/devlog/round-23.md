# 第 23 轮（把文档里写的"已知限制"真的修掉）

## 背景

> 第 22 轮写文档时，把两个**当时确实是问题**的点写进了 README / GUIDE：
> 1. "打印纸张写死 A4" -> 美洲市场要用 Letter 的话宿主只能自己 `window.print()`
> 2. "`showZoom: false` 会连带隐藏打印按钮"
>
> 既然写出来了，**就该修掉** —— 而不是永远挂在文档里当免责声明。

## ① 打印纸张不再写死 A4

### 问题

-> `usePrint` **本来就支持** `paper` 和 `margin`（`core/print` 有 `PAPER_SIZES`：A4/A3/Letter/Legal）
-> 但 `PdfViewer` 调用时是 **`paper: 'A4'` 写死的** ❌
-> 美洲市场用 **Letter**（215.9 × 279.4mm）❌
-> 包按 A4 算缩放 -> **打印可能超出页面** ❌
-> 宿主只能自己 `window.print()` -> **完全丢掉包的高亮打印能力** ❌

### 修法

- 新增 `printPaper` prop（`'A4' | 'A3' | 'Letter' | 'Legal' | { width, height }`）
- 新增 `printMargin` prop（`Partial<PrintMargin>`，mm，部分覆盖）
- 也加进 `config`（**prop > config > 默认**，和其他配置一致）
- 透传给 `usePrint`

## ② 工具栏：打印按钮和宿主插槽被 `showZoom` 连带隐藏

### 问题（其实是**两个**）

1. **打印按钮在 `showZoom` 块里**
   -> 宿主写 `toolbar={{ showZoom: false }}`（只想去掉缩放按钮）
   -> **打印按钮跟着一起消失**
   -> 但"打印"和"缩放"是**两个独立的功能**

2. **`rightSlot` 也在 `showZoom` 块里**（顺带发现的）
   -> 宿主写 `showZoom: false` -> **自己的插槽也没了**
   -> 宿主只想去掉缩放按钮，结果**自己的按钮也没了**

3. **但不能拆成两个 div**
   -> 拆开会让 `rightSlot` **渲染两次** -> 出现**两个"分享"按钮**

### 修法

-> **右侧区域合并成一个 `div`**
-> 缩放按钮 + 打印按钮 + `rightSlot` **各渲染一次**
-> `showZoom: false` 只影响缩放那几个

# 第 23 轮（续）：RTL 支持

## 背景

第 22 轮的审计报告里列了"还没修的"清单，第一条就是 **RTL**：
> "没有任何 `dir` 支持 -> 阿拉伯语/希伯来语宿主**没法用**"

既然写了"还没修"，那就**修掉**。

## 问题

-> 全仓库 **0 个 `dir` / `rtl`** ❌
-> 阿拉伯语 / 希伯来语的宿主**没法用** ❌
-> 界面还是从左往右 ❌
-> **上一页 / 下一页的箭头方向也是反的** ❌

## 修法

### ① 方向判断（`core/theme/direction.ts`，纯函数零 DOM）

```
1. 显式 `dir` prop        <- 最高
2. `locale` 是 RTL 语言    -> 'rtl'
3. `locale` 明确是 LTR     -> 'ltr'（跟着语言走）
4. 宿主页面的 `document.dir`
5. 兜底 'ltr'
```

⚠️ **第 3 条是写测试时才发现的**：
-> 宿主页面 `dir="rtl"`（阿拉伯语站点），但组件 `locale="en"` ❌
-> 如果按页面的 `dir` 走 -> **英文按钮全反了** ❌
-> 组件的语言**是显式选的** -> 应该**跟着语言走**
-> （我第一版测试断言反了，是**实现**对、**测试**错 -> 改测试 + 改实现的优先级）

⚠️ **`az` / `pa` 不在 RTL 名单里**（它们**默认是 LTR**）-> 不能误判

### ② 界面镜像（CSS）

| 部位             | 处理                                              |
| ---------------- | ------------------------------------------------- |
| 文字方向         | 根节点 `dir="rtl"` -> **浏览器自己处理**          |
| 工具栏 / 侧栏    | CSS 镜像                                          |
| **翻页箭头**     | **单独翻转**（`scaleX(-1)`）-> RTL 里"下一页"朝左 |
| **PDF 页面本身** | **不镜像**（PDF 的内容方向是它自己的事）          |

-> 工具栏翻页按钮加了 `--prev` / `--next` 类 -> 才能单独翻转
