feat(print): 打印样式 —— 摊平滚动容器 + 保留高亮 + "只打印原 PDF"选项

用户反馈："当前打印出来的展示的页面效果不对"
用户确认："保留（可以有只打印原pdf选项）"

## 实测（修复前）

```
打印态: {
  toolbarVisible: true,       ← ❌ 工具栏会被打印出来
  containerOverflow: "auto",  ← ❌ 打印时仍是滚动容器
  containerHeight: "811px",   ← ❌ 只有一屏高
  pagesHeight: "33093px",     ← 18 页全在里面，但被裁成第一屏
}
```

## 根因

**完全没有 `@media print` CSS** → 浏览器按**屏幕样式**打印。

## 修法

### ① 打印 CSS（`src/styles/viewer.css`）

```css
@media print {
  /* 该藏的藏起来 */
  .scpdf-toolbar, .scpdf-panel, .scpdf-selection-popover,
  .scpdf-selection-layer, .scpdf-annotations,
  .scpdf-text-layer,   /* ⚠️ 必须藏！否则有"幽灵文字" */
  .scpdf-link-layer, .scpdf-state { display: none !important; }

  /* 把滚动容器摊平 */
  .scpdf-container { overflow: visible !important; height: auto !important; }
  .scpdf-root { height: auto !important; overflow: visible !important; }
  .scpdf-body  { display: block !important; }
  .scpdf-pages { height: auto !important; display: block !important; }

  /* 每页一张纸 */
  .scpdf-page {
    box-shadow: none !important;
    break-after: page;
    page-break-after: always;
    transform: scale(var(--scpdf-print-scale, 1));
    transform-origin: top left;
  }
  .scpdf-page:last-child { break-after: auto; }

  /* 高亮保留，但不能用正片叠底 */
  .scpdf-annotation {
    mix-blend-mode: normal !important;
    opacity: 0.45 !important;
    print-color-adjust: exact;   /* ⚠️ 不写这个 → 浏览器省墨 → 高亮印不出来 */
  }

  @page { size: auto; margin: 12mm; }
}
```

**两个关键点**：
- **文本层必须隐藏** —— 它是透明的（给选区用的），屏幕上看不见，
  但某些浏览器会把透明文字也打出来（"幽灵文字"）
- **高亮必须 `print-color-adjust: exact`** —— 浏览器默认会**省掉背景色**（省墨）
  → 高亮印不出来

### ② 打印缩放（`src/core/print/index.ts`）

屏幕是"缩放到适合**窗口**"，打印必须"适合**纸张**"
→ 不算的话要么超出纸张被裁掉，要么缩得极小。

```ts
computePrintScale(pageSizePt, paper, margin)  // → 缩放比
computePrintPageSize(pageSizePt, paper, margin)  // → 可打印区的像素尺寸
PAPER_SIZES: A4 / A3 / Letter / Legal
```

实测：A4 页（595×842pt）在 A4 纸上 + 12mm 边距 → 缩放比 ≈ 0.886
（可打印区 186×273mm ÷ 页面 209.9×297mm）。

**不放大超过 1 倍**：打印时放大只会让字变大 + 变模糊。

### ③ `usePrint` hook（`src/hooks/usePrint.ts`）

编排：算缩放 → 应用 → **等两帧** → 打印 → 恢复。

⚠️ **必须等重排完成再打印**：`window.print()` 是同步阻塞的
→ 打印的是**当前**布局 → 缩放刚设上去还没重排 → 印出来是旧尺寸。

### ④ "只打印原 PDF"选项（用户要的）

新增 prop：

```tsx
<PdfViewer printMode="original" />        // 不带高亮
<PdfViewer printMode="with-highlights" />  // 默认，带高亮
```

→ 根节点加 `scpdf-root--print-original` → 打印时隐藏 `.scpdf-annotation`。

## 顺带修的（demo 侧）

**demo 的 header 也被打印出来了** —— 那是**宿主自己的 UI**，包的 print CSS 管不到。

⚠️ **踩了个坑**：`.demo-header { display: none }` 写在样式表里，
但 demo 用 **inline style** 设了 `display: flex`
→ **inline style 优先级高于样式表** → 打印时 header 还在。

（顺带发现 biome 的 `noImportant` 规则会把 `!important` 去掉 ——
→ 靠 `!important` 也救不了 inline style。）

→ 修法：**`display` 写进 CSS 类**，不写 inline style。

这也说明：宿主接入时要注意 —— **自己的 UI 要自己写打印样式**。

## 回归测试

**单测**（`src/core/print/index.test.ts`，10 项）：
- A4 页在 A4 纸上的缩放比 = 可打印区 / 页面
- 边距越大 → 缩放比越小
- 非法页尺寸 / 非法边距 → 1（不缩放）
- 可打印区（mm）→ 像素

**E2E**（`scripts/e2e-print.mjs`，12 项）：
- 打印时工具栏 / 文本层 / 选区层 / 标注层容器 / 浮层**全隐藏**
- **容器摊平**（`overflow: visible`）+ **不再限制高度**（18 页全在）
- 每页 `break-after: page` + 页阴影去掉
- **高亮保留** + `print-color-adjust: exact`
- **"只打印原 PDF"模式：高亮隐藏**
