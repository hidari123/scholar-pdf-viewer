## ① 打印：一页一张纸（竖向 + 横向）

### 真因（**三层**）

**① Chrome 的打印分页按【layout box】算，不按 zoom 算**

```
.scpdf-pages { zoom: 0.499 }         ← 缩放在容器上
页的 computed height = 1821.59px     ← ❌ 没被缩！
页的 getBoundingClientRect = 910px   ← ✅ 缩了（只是视觉）
```
-> 容器上的 `zoom` **不影响**后代元素的 layout box 高度 ❌
-> 每页按 1821px 算 ❌ -> 一张 A4 只有 1032px ❌ -> 塞不下 ❌
-> `break-after: page` 也救不了（块本身比纸还高）❌
-> -> **每页溢出到第二张纸** ❌ -> 后面的页被挤出打印范围 ❌

**② 页的宽高是【内联样式】**（`style={{ width, height }}`）❌
**③ canvas 的宽高【也是内联样式】**（`canvas.style.width = '1407px'`）❌
-> 盖过 `width: 100%` ❌ -> canvas 比页还宽 ❌ -> 右边被裁掉 ❌

**④ 横向时缩放没按横向纸张算** ❌
-> 横向 A4 的可印区是 **297 × 210mm**（不是 210 × 297）✅
-> 不换 -> 18 页印成 **36 张** ❌

### 修法

-> 打印时用 **`calc()` 把页的宽高写死**成"原尺寸 × 缩放"（`!important`）✅
-> **只看 calc，不看 zoom** ✅（zoom 会缩两次 ❌）
-> 打印时把 **canvas 拉回 100%** ✅
-> 新增 `printOrientation` prop ✅

### 实测

```
竖向: 页 703 × 910px  -> 打印 PDF **18 张纸 / 18 页** ✅
横向: 页 543 × 703px  -> 打印 PDF **18 张纸 / 18 页** ✅  （修复前 36 张 ❌）
```

## ④ 批注详情的位置 / 宽度

### 真因（**两处**）

**① 合并组只有**一个**图标 -> 第二条找不到锚点**

```ts
// 之前的查找（精确匹配）
`.scpdf-sticky-note__icon[data-note-id="${activeAnnotationId}"]`;
```
-> 合并组的图标只有 `data-note-id={first.id}`（**第一条**）❌
-> 选**第二条** -> **找不到** ❌ -> 锚点**保持旧值** ❌
-> -> 面板停在**首页** ❌（用户反馈"第二个还是出现在 PDF 首页"）

**② 滚动定位"跑来跑去" —— 两套逻辑在打架**
-> rAF 重试 + `scroll` 事件监听**各自跑** ❌ -> 互相覆盖 ❌

### 修法

-> 图标带**整组**的 id（`data-note-ids`）✅
-> 新增 `findStickyNoteIcon` ✅
-> ⚠️ **踩坑**：`[data-note-ids~="b"]` **不管用** ❌（`~=` 只按空格分隔）❌
-> 改成**自己遍历比对** ✅
-> 锚点改成**一个 rAF 循环**（量到为止 + 一直跟随）✅
-> 面板宽度 320 -> **360px** ✅
-> 工具栏 `flex-wrap: wrap` -> **`nowrap`** ✅（13 个按钮从 2 行变 1 行）

### 实测

```
第一条: panel={x:402,y:242,w:362}  note={x:402,y:190}  dy=52  ✅
第二条: panel={x:402,y:242,w:362}  note={x:402,y:190}  dy=52  ✅  ← 之前是"首页"
滚动后: panel={x:402,y:12,  w:362}  note={x:402,y:-60}  dy=72  ✅  跟着走
工具栏: 13 个按钮 -> **1 行** ✅                      ← 之前是 2 行
```
