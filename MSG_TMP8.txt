fix(demo): 修 Vite 预打包缓存过期导致 demo 白屏 + 启动前自动构建

## 现象

启动 demo 后**白屏 + 500**：

```
Failed to resolve import "@scholar-club/pdf-viewer/styles.css" from "src/App.tsx"
```

## 根因

demo 消费的是**包的 `dist/`**（workspace 软链 → `demo/node_modules/@scholar-club/pdf-viewer`
指向仓库根）。

在 demo **运行期间**执行 `pnpm build`（`dist/` 被删了重建）
→ Vite 对这个 workspace 包的**预打包缓存**失效
→ 之后所有请求都报"解析不了"。

⚠️ **迷惑点**：`require.resolve('@scholar-club/pdf-viewer/styles.css')` 在 Node 侧
是**能**解析的（`dist/styles.css` 明明存在）
→ 看起来像"文件不存在"，其实是 Vite 的**预打包缓存**过期了。

日志里能看到这个顺序：

```
[vite] hmr update /@fs/.../dist/styles.css
[vite] hmr invalidate /@fs/.../dist/index.js Could not Fast Refresh ("EN_MESSAGES" ...)
[vite] hmr update /src/App.tsx
[vite] Pre-transform error: Failed to resolve import "@scholar-club/pdf-viewer/styles.css"
```

## 修法（两处）

### ① `demo/vite.config.ts`：不预打包 workspace 包

```ts
optimizeDeps: {
  exclude: ['@scholar-club/pdf-viewer'],
},
```

→ Vite **按源码直接服务**它 → `dist/` 重建后**不需要重启**，也不会缓存过期。

### ② `scripts/demo.mjs`：启动前先构建包

```js
console.log('[demo] 构建包（dist/）…');
const build = spawnSync('pnpm', ['build'], { cwd: root, stdio: 'inherit', ... });
if (build.status !== 0) { ... process.exit(1); }
```

→ 每次 `pnpm demo` 都保证 `dist/` 是最新的 → 不会再出现白屏。
