# 第 17 轮（用户提了 5 件事）

## ① 批注 hover 的编辑/展开按钮 + 富文本展示

**"框就消失"**：内容框是图标的**兄弟节点** -> 鼠标移过去 -> 图标 `onMouseLeave` -> 清状态 -> 框消失
-> 用 `event.relatedTarget` 判断"是不是移到相关兄弟节点上" -> 是就不清

**编辑/展开按钮**：新增 `onAnnotationEdit` / `onAnnotationExpand` props
-> 宿主没传 -> **不渲染**（老规矩）

**富文本展示**：之前直接渲染 `content`（HTML 字符串）-> 用户看到 `<p>...</p>`
-> 新增 `RichTextPreview` + `sanitizeRichTextHtml`（白名单 + 去事件属性 + 检查链接协议）

- 提交：`7c2acae`

## ② 退格删高亮

-> 监听 **`document`**（容器上的监听要求容器有焦点 -> 用户点完高亮焦点在 body -> 没反应）
-> 保护：没选中 / 宿主没给删除回调 / 输入框里 / 有文字选区 -> 都不删

- 提交：`a676ba0`

## ③ 目录还是无法点击跳转（三层根因）

1. 宿主要写 100+ 行，而且**最容易漏"通知包"那一步** -> 目录点了没反应
2. `collectOutlineRefs` **只收集数组形态的 dest** -> 命名目标永远解析不出来
3. `setOutlinePageMapper(mapper)` -> **mapper 是函数** -> React 把它当**惰性初始化器**调用 -> 状态成了 null

-> 新增 `resolvePageRef`（异步解析器）-> **包自己解析**
-> demo 少了 **100+ 行**

- 提交：`20f4ff7`

## ④ 富文本编辑框：定位 + 黑框 + 重复输入框

**定位**：之前**居中** -> 选区在屏幕底部时看不到
-> 新增 `anchorRect` -> `position: fixed` + JS 算视口坐标 -> **贴着选区**
-> 有锚点时**不遮罩**

**黑框 + 重复输入框**：TipTap 的结构是"外层有边框 + 内层也有边框"
-> CSS：外层不画边框，边框只画在 `.ProseMirror` 上
-> 占位符改用 **TipTap 官方 `Placeholder` 扩展**

**"每写一个东西下面就冒出来一条"**：`editor.mount(host)` 对同一个 host 调了多次
-> 实测 **`.ProseMirror` 有 9 个** ❌
-> **把编辑器缓存到 host 上** -> 复用

- 提交：`0813fbd`
