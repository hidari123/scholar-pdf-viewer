feat(demo): 宿主侧的高亮持久化（localStorage + 防抖）

补齐 PLAN-ROUND13 §3b② 的**宿主侧持久化**（之前只有内存态 + 手动 JSON 导入导出）。

## 为什么在宿主而不是包里

包的边界（v2 原则）：**包只给"格式 + 纯函数"，不碰存储**。

→ 换后端（localStorage → IndexedDB → 自己的接口）**不用改包**
→ demo 里只改了 `highlight-store.ts` 一个文件

## 实现（`demo/src/highlight-store.ts`）

| 函数                     | 作用                                     |
| ------------------------ | ---------------------------------------- |
| `loadHighlights(id)`     | 从 localStorage 读（用包的 `importHighlights` 校验） |
| `saveHighlights(id, hs)` | 用包的 `exportHighlights` 写             |
| `createDebouncedSaver()` | **防抖 500ms** → 连续操作合并成一次写    |

⚠️ 读失败 / 配额满 / 隐私模式 → **静默降级**（不能让宿主整个崩掉）
⚠️ 保存器放在**组件外**（`useMemo`）→ 不会因重渲染重建（重建会丢掉待保存的数据）

## 接进 demo

- **文档切换 → 加载对应文档的高亮**（`useEffect` on `[documentId]`）
- **每次改动都保存**（用户要求"如有接口则每次改动都保存到接口"）
  → `setHighlights` 里调 `saver.schedule(documentId, value)`
