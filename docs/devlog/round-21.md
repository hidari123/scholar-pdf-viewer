## ① 链接弹窗：内置编辑器根本没有

- `RichTextEditor`（宿主没装 TipTap 的兜底）-> `execCommand('createLink', false, '')` -> **空链接** ❌
- 只有 `TipTapEditor` 有 `LinkPopover` -> **宿主没装 TipTap 点链接毫无反应** ❌
- **修**：内置编辑器**共用同一个 `LinkPopover`** ✅

## ② 删除线 icon 只有上半截

- path 只有 "S" 的上半截 -> 看着像个 "C" ❌
- **修**：两条折线拼出完整的 "S"（和 `italic`/`underline` 同一套画法）✅

## ③ fitWidth 留白 + 缩放就近取整

### 两边留白

- 之前减 `32` -> 页宽 1408px > 容器 1384px -> **横向溢出** -> **下面有横向滚动条** ❌
- 改成减 `48`（左右各 24）-> 页宽 1336px -> 不溢出 + **有留白** ✅

### 缩放"就近取整到 10%"

- 之前 `scale + 0.1` -> 237% -> **247%** ❌
- **修**：新增纯函数 `stepScaleByQuantum` -> 237% -> **240% / 230%** ✅

### ⚠️ 踩过的坑：别按高度限制 fitWidth

- "宽高取小的" -> 竖版页按宽度 218%、按高度 99% -> **取小的 = 90%** ❌
- 页变得很小 -> **所有依赖坐标的 E2E 全挂** ❌
- **只按宽度** ✅

## ④ 链接不跳转 + 光标不是小手

### 4.1 点链接没反应

- **高亮的 handler 先跑** -> 点空白时 `stopPropagation()` -> **链接的处理被挡住** ❌
- **修**：**链接先处理** ✅

### 4.2 光标是文字光标

- 链接层 `pointer-events: none`（故意的）-> **永远不会成为 hover 目标** -> CSS 的 `cursor: pointer` 永远不生效 ❌
- **修**：`mousemove` -> 按坐标命中 -> 手动改光标 ✅

### ⚠️⚠️ 踩过的坑：不能用 React state 切光标

- `setState` -> 每次 mousemove 都可能**重渲染** -> **文本层被重建** -> **正在拖的选区没了** ❌
- **12 个选区相关的 E2E 全部挂掉** ❌
- **修**：**直接改 DOM 的 style** -> 不重渲染 -> 拖选不受影响 ✅

### 4.3 demo 补 `onInternalLink`

- demo 只传了 `onExternalLink` -> 内部链接点了没反应 ❌
- 补上 -> 跳到对应页 ✅

## 顺带修的

- **E2E 断言**："浮层锚定" 从"gap 必须一致"改成"**距离**要小"
  -> 浮层放不下会**翻到上方**（正确行为）-> 缩放后 gap 从 8px 变 -126px，但**还是贴着选区** ✅
