feat(zoom): 打开缩略图/目录时 PDF 自动重新适配（WPS 式）

用户反馈："缩略图或者文档目录打开的时候 右侧的pdf自动缩放 跟wps保持一致"

## 实测（修复前）

```
初始:      scale=230%  containerW=1384  pageW=1408
开缩略图:  scale=230%  containerW=1139  pageW=1408   ← ❌ 页比容器还宽（横向溢出）
```

→ 打开侧栏后页**横向溢出**（要横向滚动才能看全）→ 很难用。

## 根因（三层，每层都要修）

### bug 1：适配宽度被"用户手动缩放"误判

```ts
initialFitScaleRef.current = scale;   // ❌ 记的是**旧**的 scale
...
if (scale !== initialFitScaleRef.current) {
  userZoomedRef.current = true;        // ❌ 初始适配自己把自己判成"用户缩放过"
}
```

→ `ResizeObserver` 里的 `if (userZoomedRef.current) return;` → **永远不重适配**。

### bug 2：hook 返回新对象 → effect 每次渲染都重跑

```ts
// useSelectionPreservation
return { save };              // ❌ 每次渲染都是新对象
```

→ `handleZoomChange` 每次都变 → `applyScale` → `setScale` → `zoom` 每次都变
→ 依赖 `zoom` 的 `useEffect` **每次渲染都重跑**
→ cleanup 把 `ResizeObserver` 拆了重建 → **`lastWidth` 被重置成当前宽度**
→ **宽度变化永远检测不到**！

（实测：observer 的回调只会看到 `width: 1384`，永远看不到 1139）

### bug 3：`useZoom` 返回新对象

```ts
return { zoomIn, zoomOut, fitWidth, fitPage, setScale };   // ❌
```

→ 同样的问题。

## 修法

### ① 引入**适配模式**（`fitMode`）

```ts
type FitMode = 'width' | 'page' | null;
// 'width' → 适配宽度（容器变窄 → 自动重适配）
// 'page'  → 适配整页（容器尺寸变了 → 重算）
// null    → 用户手动定的比例 → **不动**（尊重用户的偏好）
```

- `useZoom` 内部维护 `fitModeRef`
- `fitWidth()` → 设成 `'width'`；`fitPage()` → 设成 `'page'`
- **用户手动缩放**（`setScale`）→ 设成 `null`（退出适配模式）

### ② `useZoom` 拆成两个函数

```ts
applyScale(next)   // 内部用，**不碰**适配模式
setScale(next)     // 公开，手动缩放 → **清掉**适配模式
```

→ 避免了"fitWidth 内部调 setScale → 把自己的模式清了"的冲突。

### ③ 所有 hook 的返回值用 `useMemo` 包住

（`useSelectionPreservation` / `useCurrentPage` / `useTextSelection` / `useVisiblePages` / `useZoom`）

→ 返回值**稳定** → 依赖它的 effect **不会**每次渲染都重跑。

### ④ ResizeObserver 按模式决定要不要重适配

```ts
if (fitMode === 'width') zoom.fitWidth(width, pt.width);
else if (fitMode === 'page') zoom.fitPage(width, height, pt.width, pt.height);
// fitMode === null → 不动
```

⚠️ **只处理"宽度变了"**（高度变化是滚动条出现/消失 → 会抖）。

## 实测（修复后）

```
初始:      scale=230%  containerW=1384  pageW=1408
开缩略图:  scale=180%  containerW=1139  pageW=1102   ← ✅ 页完整可见
关缩略图:  scale=220%  containerW=1384  pageW=1408   ← ✅ 恢复（±10%，量化步长）
手动放大后开面板: scale 不变                              ← ✅ 不覆盖用户偏好
```

## 回归测试

**E2E**（`scripts/e2e-sidebar-fit.mjs`，10 项）：

- 开缩略图 → 容器变窄 + 缩放变小 + **页不横向溢出** + 页宽接近容器宽
- 关缩略图 → 缩放恢复（±10%，一个量化步长）
- **手动缩放后开面板 → 不覆盖用户的比例**
- 全程无 JS 错误
